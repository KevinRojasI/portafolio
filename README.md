## 🚀 Despliegue

### GitHub Pages (Recomendado - Gratis)

1. Sube el repositorio a GitHub
2. Ve a Settings → Pages
3. Selecciona "Deploy from a branch"
4. Rama: `main` / Carpeta: `/ (root)`
5. ¡Tu sitio estará en: `https://username.github.io/portafolio`
