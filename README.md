# Portafolio personal

Este es mi portafolio personal. Aquí presento mi experiencia, los servicios que ofrezco y las tecnologías con las que trabajo.

El sitio está hecho con HTML, CSS y JavaScript, y está adaptado para computadores y dispositivos móviles.

## Estructura del proyecto

```
portafolio/
├── index.html              # Página principal
├── README.md              # Este archivo
├── .gitignore             # Archivos a ignorar en Git
├── css/
│   └── style.css          # Estilos del sitio
├── js/
│   └── script.js          # Funciones del sitio
├── img/                   # Imágenes
├── assets/                # Otros recursos
└── video/                 # Video de presentación
```

## Tecnologías

- HTML
- CSS
- JavaScript
- Font Awesome

## Ejecución local

No se necesitan instalaciones adicionales. Abre `index.html` en un navegador moderno.
